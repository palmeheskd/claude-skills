# Claude Skills Library

A company-wide library of Claude Code skills.

## Usage

Add this repo as a skills source in your Claude Code settings:

```json
{
  "skills": {
    "sources": [
      "github:palmeheskd/claude-skills"
    ]
  }
}
```

## Skills

| Skill | Description |
|-------|-------------|
| [skill-creator](skill-creator/) | Create and structure new skills for this library |
